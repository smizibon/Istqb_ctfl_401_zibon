# Chapter 2 Exercises — Testing Throughout the SDLC
*20 questions, closed book, ~90 s each. Target ≥ 80% (16/20). Answers: [`../answer-explanations/chapter-02-answers.md`](../answer-explanations/chapter-02-answers.md).*

**1.** In a sequential (V-model) project, detailed test design begins from documentation well before executable code exists. This illustrates that:
a) Test design requires running software
b) Test activities can be prepared early based on available work products
c) The V-model forbids early test design
d) Sequential models have no test levels

**2.** Which is a challenge testing faces in a DevOps environment?
a) Feedback is too slow to be useful
b) The deployment pipeline and test automation must themselves be developed and maintained
c) Releases become less frequent, increasing risk
d) DevOps removes the need for regression testing

**3.** "Shift-left" in testing means:
a) Starting test execution earlier in the schedule only
b) Moving all testing to the development phase and cancelling system test
c) Testing work products earlier and involving testers from the start of the lifecycle
d) Offshoring testing to a team in an earlier time zone

**4.** After each sprint, the team discusses what went well and what to improve in testing. This is:
a) A retrospective
b) An inspection
c) A walkthrough
d) A test completion review

**5.** Testing that a single class correctly calculates VAT, isolated from the rest of the system using stubs, is:
a) Component testing
b) Component integration testing
c) System testing
d) Acceptance testing

**6.** Testing the data exchanged between the invoicing module and the tax module is:
a) Component testing
b) Component integration testing
c) System testing
d) Beta testing

**7.** End-to-end testing of the complete, integrated system against its requirements and use cases is:
a) Component integration testing
b) System testing
c) Component testing
d) Confirmation testing

**8.** Users at their own workplace verify the system supports their business processes before rollout. This is:
a) Alpha testing
b) Operational acceptance testing performed as alpha
c) User acceptance testing (a form of beta-style site testing)
d) Component testing

**9.** Operational acceptance testing is typically performed by:
a) End customers
b) Operations/administration staff (admins, helpdesk, security, database administrators)
c) Developers
d) External regulators only

**10.** Which statement about functional and non-functional testing is TRUE?
a) Non-functional testing can only be done at system level
b) Functional and non-functional testing can be performed at every test level
c) Functional testing is always black-box; non-functional is always white-box
d) Component testing cannot be functional

**11.** A tester derives tests from the system's specification without seeing the code. The derivation basis makes this:
a) White-box testing
b) Black-box testing
c) Experience-based testing
d) Debugging

**12.** A defect in the search function is fixed. The team re-runs the test that previously failed. This is:
a) Regression testing
b) Confirmation (re-)testing
c) Smoke testing
d) Maintenance testing

**13.** After installing the search fix, the team also retests checkout and login "just in case." This is:
a) Confirmation testing
b) Regression testing
c) Alpha testing
d) Static testing

**14.** Regression testing:
a) Runs only after defect fixes
b) Runs after any change, including new features, enhancements and environment changes
c) Applies only at system test level
d) Is unnecessary in agile projects

**15.** A build is deployed to the test environment and a small suite verifies its most crucial functions work before deeper testing starts. This suite is:
a) A full regression suite
b) A smoke test suite
c) An inspection suite
d) A confirmation suite

**16.** The company upgrades the database from version 11 to 12 and re-checks data integrity and application behaviour. The maintenance trigger is:
a) Modification
b) Migration
c) Retirement
d) Enhancement

**17.** A 15-year-old system is replaced by a new one; old data must be archived and verified. The maintenance trigger is:
a) Migration
b) Modification
c) Retirement
d) Hotfix

**18.** The scope of maintenance testing is primarily determined by:
a) The size of the test team
b) Impact analysis of the change and the areas it could affect
c) The number of pages in the test plan
d) The customer's contract penalty clauses

**19.** In an iterative/agile project, which testing concern grows the most over time?
a) Component testing
b) Regression testing
c) Requirements reviews
d) Unit testing

**20.** Emergency fixes deployed to production typically require:
a) Only confirmation testing of the fix
b) Both confirmation of the fix and regression testing around it
c) No testing due to urgency
d) A new full requirements analysis
