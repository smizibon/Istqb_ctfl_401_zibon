1 · BVA / EP generator

K3

Random range, one random question: full 2-value BVA set, full 3-value BVA set, or minimum EP test count. how it's done ↗

✏️ Solved example (print)

Field accepts 15–70. List the complete 2-value BVA set.

Rule: 2-value (ISTQB default): {boundary, nearest neighbour}. Boundaries: 15 and 70.

Boundary 15 → {15, 14} · boundary 70 → {70, 71}. Count one by one: 14, 15, 70, 71 → 4 tests.

2 · Coverage meter drill

K3

Random snippet + random test set → compute statement coverage % and branch coverage %. how it's done ↗

✏️ Solved example (print) 
1  read x
2  if (x > 10):        # decision D
3      print("high")
4  print("end")

Test 1: x = 15. Statements: 4 total (1, 2, 3, 4); x=15 executes 1, 2, 3, 4 → 4/4 = 100% statement. Branches: D-T and D-F; only D-T taken → 1/2 = 50% branch.

Theorem: 100% branch ⇒ 100% statement — never the reverse. Add x = 5 (takes D-F) → 100% branch.

K3

✏️ Solved example (print)

Conditions: Gold member (Y/N), Order > €100 (Y/N) → full rules = 2 × 2 = 4.

Stated collapse: non-gold customers get no discount regardless of order size → the two Non-gold rules merge (Gold=F, Order=−) → minimum = 3 tests.

4 · State-machine stepper — the music player

K3

Fire events at the machine: valid transitions animate the dot; illegal (event, state) pairs shake red. Cover all 5 valid transitions for 0-switch completeness. how it's done ↗

✏️ Solved example (print)

Music player: states Idle, Playing, Paused; events Play / Pause / Stop.

All 5 valid transitions (0-switch = each exercised once → 5 tests): Play: Idle→Playing · Play: Paused→Playing · Pause: Playing→Paused · Stop: Playing→Idle · Stop: Paused→Idle.

Invalid pairs (also test cases — the system should reject them): Stop in Idle · Play in Playing · Pause in Idle · Pause in Paused (4 illegal pairs of 9).

Count TRANSITIONS, not states; invalid (event, state) pairs are also test cases.
